# 개인용 문제집 디지털화 & 오답 재풀이 (로컬 프로토타입)

완전 로컬 실행 전용 프로토타입. 회원가입/로그인/결제/클라우드/서버 배포 전혀 없음.
PC 1대에서만 실행하고, 태블릿은 같은 집 와이파이 대역에서 브라우저로 접속한다.

기존 "마클리" 앱(`main.py`, `static/`)과는 완전히 독립된 별개 프로젝트다. 이 폴더
안의 코드만으로 동작하며, 상위 저장소의 다른 코드를 참조하지 않는다.

## 0. 설치

```bash
cd local-workbook-prototype
pip install -r requirements.txt

# Gemini API 키는 코드에 하드코딩하지 않고 환경변수로만 넘긴다.
export GEMINI_API_KEY="여기에 본인 키"
```

### Windows에서 매번 명령어 치기 귀찮다면 (더블클릭 실행)

`pip install` 한 번만 터미널에서 해두면, 그 다음부터는 `.bat` 파일 더블클릭으로 실행할 수 있다.

1. **API 키는 한 번만 영구 등록** (아무 cmd 창에서 한 번만 실행, 그 뒤로는 다시 안 해도 됨):
   ```
   setx GEMINI_API_KEY "본인의 Gemini API 키"
   ```
   실행 후 열려있던 cmd 창은 모두 닫는다 (새로 여는 창부터 적용됨).

2. `local-workbook-prototype` 폴더 안의 `.bat` 파일을 그냥 더블클릭. **`run_live.bat` 하나만
   알아도 충분하다** — 나머지는 그게 안 될 때 쓰는 보조 도구들이다.

## 1. 가장 쉬운 방법 — 즉석 풀이 모드 (`run_live.bat`)

```
run_live.bat 더블클릭
```

책 전체를 미리 나누지 않고, **지금 보는 페이지 한 장만** 그 자리에서 처리한다.
수백 페이지짜리 책도 기다림 없이 바로 시작할 수 있다.

1. 사이드바에서 PDF 파일을 고른다 (폴더에 PDF만 넣어두면 자동으로 목록에 뜸).
2. **처음 여는 파일이면** "어느 페이지부터 풀까요?" 화면이 뜬다. 페이지 번호를 바꾸면
   미리보기가 바뀌니, 표지/목차/개념 설명이 아니라 실제 문제가 시작하는 페이지를 골라
   "이 페이지부터 풀기".
3. 그 페이지 안의 문제만 찾아서 하나씩 보여준다 (2단 편집도 왼쪽 칸 → 오른쪽 칸 순서로
   칸 너비만큼 자름). 화면 왼쪽에 문제와 보기, 오른쪽 전체가 풀이 공간(손글씨,
   `streamlit-drawable-canvas` 설치 시). PDF 선택·페이지 이동은 접혀 있는 사이드바에 있다.
4. 객관식은 보기 목록을 눌러 **고르기만** 하고, **채점하기**를 눌러야 채점된다 (잘못 눌러도 안전).
   주관식은 입력창 + 채점하기.
5. **미리 채점**: 문제가 뜨는 순간 그 문제와 다음 2문제(필요하면 다음 페이지까지)를 AI가 뒤에서
   미리 풀어둔다. 그래서 채점하기를 누르면 대부분 바로 결과가 나온다. 한 번 푼 문제는
   `answers.json`에 저장되어 다시 AI를 부르지 않는다.
6. 1번 틀리면 힌트를 보고 다시, 2번 틀리면 **풀이식 빈칸 채우기**(㉠ ㉡ 빈칸을 채우고 확인) 후
   정답 공개. 페이지의 문제를 다 풀면 자동으로 다음 페이지.
7. 마지막 위치가 저장되어, 다음에 같은 PDF를 열면 이어서 풀 수 있다.
   사이드바의 이전/다음 쪽, "다른 페이지로 이동"으로 언제든 옮길 수 있다.

**문제를 못 찾거나 이상하게 잘렸을 때**
- 페이지에서 문제 번호("1." "1)" 형식)를 글자로 못 찾으면 자동으로 AI가 페이지 이미지를
  보고 문제 영역을 찾는다 (스캔본도 가능).
- 잘못 잘렸으면 문제 아래 "전체 페이지 보기 / 문제가 이상하게 잘렸어요" → "AI로 이 페이지
  문제 다시 찾기". 문제가 없는 페이지면 "다음 쪽"으로 건너뛰면 된다.
- 한 문제가 다음 페이지로 넘어가는 경우 넘어간 부분은 잘린 이미지에 안 들어간다
  ("전체 페이지 보기"로 확인 가능).

출판사 정답표를 전혀 안 읽기 때문에 "다단 표라서 파싱이 깨지는" 문제는 발생하지 않는다.
대신 Gemini API 키가 꼭 필요하고(`setx GEMINI_API_KEY "..."`), 도형/그래프처럼 그림
해석이 까다로운 문제는 AI가 가끔 틀릴 수 있다 — 오답 화면에서 정답/풀이가 바로 보이므로
즉석에서 확인할 수 있다.

결과는 `<PDF파일명>_bypage/` 폴더에 저장된다 (페이지 이미지, 잘린 문제, 정답, 풀이 기록).

## 2. 수동/단계별 방식 (즉석 모드가 안 맞을 때, 또는 세밀한 보정이 필요할 때)

아래는 각 단계를 따로 실행하고 싶을 때 쓰는 기존 방식이다. 위 즉석 모드로 충분하면
안 읽어도 된다.

- `run_split.bat` — PDF 파일명/정답 페이지 번호를 물어보고 문제 분할+정답 파싱 실행 (1일차)
- `run_ai_solve.bat` — 정답표를 읽는 대신 AI가 문제를 한꺼번에 미리 다 풀어서 정답 생성
- `run_answers_from_text.bat` — 정답을 메모장에 직접 타이핑해서 answers.json 만들기 (비상 경로)
- `run_correct.bat` — 프로젝트 폴더 이름을 물어보고 1분 눈 검수 화면 실행
- `run_app.bat` — 태블릿 풀이 화면 실행 (정답을 미리 다 만들어둔 프로젝트용)

## 3. 사용 순서 (0일차 -> 3일차, 수동 방식 기준)

### 0일차 (30분 이내) — 텍스트 레이어 확인 (가장 먼저 할 것)

```bash
python scripts/run_step0_check_text_layer.py ./math_grade1.pdf
```

- 모든 페이지가 `TEXT`로 나오면 -> 순수 좌표/텍스트 분할로 충분.
- 일부/전부가 `IMAGE-ONLY`로 나오면 -> 해당 페이지는 OCR 경로(`--answer-ocr`,
  `pytesseract` 설치)가 필요하고, 문제 분할도 자동이 아니라 `correct_app.py`에서
  수동으로 경계를 나눠야 한다.

### 1일차 — 문제 분할 + 정답표 파싱

```bash
python scripts/run_split_and_parse.py \
  --project ./math_grade1_project \
  --pdf ./math_grade1.pdf \
  --answer-pages 41,42 \
  --start-page 14
```

`--start-page`(선택)는 실제 문제가 시작하는 페이지. 앞쪽 표지/목차/개념 설명 페이지의 번호가
문제로 잘못 잡혀 번호 순서가 밀리는 걸 막는다.

`--answer-pages`는 책 뒤편 "빠른 정답표"가 있는 실제 PDF 페이지 번호(1-based)를
직접 확인해서 넘겨준다 (책마다 위치가 달라 자동 탐지가 불안정하기 때문에 사람이
지정하는 것으로 설계했다).

결과물:
```
math_grade1_project/
├── pages/            # 페이지별 원본 이미지 (중간 산출물)
├── questions/        # q_01.png, q_02.png ... (문제별 최종 이미지)
├── boundaries.json   # 문제 경계 (자동 탐지 + 수동 보정 반영)
└── answers.json       # 문항별 정답/유형(객관식·단답형·서술형)/도형여부
```

### 1분 눈 검수 — 정답 확인 + 경계 보정

```bash
streamlit run correct_app.py -- --project ./math_grade1_project
```

- **정답 검수 탭**: 문항별 정답/유형/도형여부를 훑어보고 잘못된 것만 고친 뒤
  "모두 저장".
- **문제 경계 보정 탭**: 자동 분할이 실패했거나 어긋난 문제를, 페이지 이미지를
  클릭해서 나온 y좌표를 표에 입력하는 방식으로 보정("클릭 2번"으로 시작/끝 지정).
  `streamlit-image-coordinates`가 설치되어 있으면 클릭 즉시 좌표가 표시된다.

#### (권장) 정답표를 아예 읽지 않고, AI가 문제를 직접 풀어서 정답 만들기

출판사 정답표 레이아웃 문제를 근본적으로 피해가는 방법. 문제 분할(`run_split.bat`)까지만
끝내두면, 정답표 페이지가 몇 쪽인지 몰라도/정답표가 없어도 상관없다.

```
run_ai_solve.bat 더블클릭 -> 프로젝트 폴더 이름 입력
```

각 문제 이미지를 Gemini가 하나씩 직접 보고 풀어서 정답·유형·간단한 풀이까지
`answers.json`에 저장한다 (문항마다 바로 저장되므로 중간에 창을 닫아도 그때까지
푼 건 남아있다). 중학교 수준 문제는 꽤 안정적으로 맞히지만, 도형/그래프처럼
그림 해석이 까다로운 문제는 1분 눈 검수에서 한 번 더 확인하는 걸 권장한다.
이미 손봐둔 유형/도형여부가 있으면 덮어쓰지 않는다.

#### 정답표가 다단(여러 칸) + 괄호 설명이 섞여서 자동 파싱이 많이 틀렸다면

이런 레이아웃은 가벼운 규칙 기반 파서로는 한계가 있다. 위의 AI 풀이로도 안 되거나
API 키가 없다면, UI에서 칸칸이 고치는 것보다 메모장에 정답을 쭉 타이핑해서
한 번에 다시 만드는 게 훨씬 빠르다:

1. 프로젝트 폴더 안에 텍스트 파일(예: `answers_manual.txt`)을 만들고, 책을 보면서
   한 줄에 한 문항씩 입력한다:
   ```
   1. 0.25, 유한소수
   2. 0.125, 유한소수
   3. 0.727272..., 무한소수
   ```
2. `run_answers_from_text.bat` 더블클릭 (또는
   `python scripts/answers_from_text.py --project ./프로젝트 --text ./answers_manual.txt`)

기존에 "정답 검수" 탭에서 손봐둔 유형/도형여부/해설은 그대로 유지된다.

### 2~3일차 — 태블릿 풀이

```bash
streamlit run app.py --server.address 0.0.0.0
```

터미널에 출력되는 `Network URL` (예: `http://192.168.0.12:8501`)을 태블릿
브라우저에 입력해 접속한다. PC와 태블릿이 **같은 와이파이**에 연결되어 있어야 한다.

화면에서:
1. 사이드바에서 단원(프로젝트 폴더)을 선택하고 "이어서 풀기" 또는 "처음부터".
2. 문제를 카드로 넘기며 풀이 -> 제출 즉시 자동채점.
3. 오답이면 [쌍둥이 문제 도전](Gemini가 이미지 그대로 보고 유사 문제 생성) 또는
   [넘어가기].
4. 도형/그래프/작도처럼 그림이 필수인 문제는 "정답 검수" 탭에서 도형 체크를
   해두면 쌍둥이 생성 대신 "정답/해설 다시 보기"로 대체된다.
5. 단원을 다 풀면 결과 요약 화면(정답률, 틀린 문제, 재도전 후 이해/여전히 틀림).

풀이 이력은 `math_grade1_project/log.csv`에 누적 저장된다 (분석 화면은 없음,
저장만 함).

```
│       ├── ai_solver.py        # 문제 이미지를 보고 AI가 직접 풀기

│   ├── run_step0_check_text_layer.py
│   ├── run_split_and_parse.py
│   ├── solve_with_ai.py
│   └── answers_from_text.py
├── live_app.py                   # ⭐ 즉석 풀이 모드 화면 (고른 페이지부터 한 장씩 처리하며 풀기)
├── live_engine.py                # 즉석 모드의 페이지 준비 + 정답 저장 + 백그라운드 미리 풀기

└── app.py                        # 태블릿 풀이 화면 (정답을 미리 만들어둔 프로젝트용)
```


## 5. 향후 확장 (지금 구현 안 됨, 구조만 고려)

국어/과학 등 다른 과목을 추가할 때는 `subjects/korean/`, `subjects/science/`
아래에 `answer_rules.py`(자동채점/재도전 가능 여부 규칙)와 같은 이름의 인터페이스를
구현한 모듈을 추가하고, `app.py`가 과목 선택에 따라 불러오는 모듈만 바꾸면 된다.
지문 기반 문제 그룹핑(국어) 등 과목별 로직은 이번 범위가 아니다.

## 6. 알아두어야 할 한계 (개인용 프로토타입이므로 의도적으로 생략한 것)

- 인증/멀티유저/권한 없음 — 같은 와이파이에 있는 누구나 접속 가능한 로컬 서비스.
- 표 형태 정답표는 "번호가 1부터 순서대로 증가한다"는 가정에 기반한 정규식 파서로
  처리한다. 레이아웃이 심하게 어긋나는 다단 표는 자동 파싱이 틀릴 수 있으니
  1분 눈 검수에서 반드시 확인한다.
- 문제 경계가 페이지 3개 이상에 걸치는 경우 등 매우 예외적인 레이아웃은
  `correct_app.py` UI로 편집이 안 되고 `boundaries.json`을 직접 고쳐야 한다.
